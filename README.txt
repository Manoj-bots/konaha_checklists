MOBILE / GITHUB PAGES

1. Open script.js.
2. Replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE with the same Apps Script /exec URL used by laptop.
3. Upload the CONTENTS of this mobile folder to the root of the GitHub repo.
4. Enable GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
5. Open the Pages URL on mobile and refresh once after deployment.

Task changes sync individually. The app pulls Google Sheets every 5 seconds, so a checkbox changed on laptop should appear on mobile shortly after, and vice versa.
