LAPTOP / LIVELY

1. Open script.js.
2. Replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE with the same Apps Script /exec URL used by mobile.
3. Add this laptop folder to Lively using index.html.
4. Task changes sync individually to Google Sheets.
5. Shared state is pulled every 5 seconds.
6. The Save Today to Sheets button writes history (Daily_Summary + Task_Log).
